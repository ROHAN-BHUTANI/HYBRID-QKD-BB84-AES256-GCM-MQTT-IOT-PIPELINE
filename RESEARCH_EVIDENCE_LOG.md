# Research Evidence Log

| Topic / Requirement | Authoritative Source | Key Finding / Formula | How Applied in System |

| **Privacy Amplification & Leftover Hash Lemma** | Bennett et al. (1995) *IEEE Trans. Inf. Theory* 41(6):1915–1923; Tomamichel et al. (2012) *Nat. Commun.* 3:634 | For 2-universal hash family $\mathcal{H}$, extractable secret length is $\ell \le H_{\min}(X \mid E) - \text{leak}_{\text{EC}} - 2\log_2(1/\epsilon_{\text{sec}})$. A Toeplitz matrix generated from a public seed is 2-universal over $\text{GF}(2)$. | Implemented `ToeplitzHash` over $\text{GF}(2)$ using CSPRNG seed. Output key length bounded by empirical finite-key formula. |
| **Quantum Channel Depolarizing Error** | Nielsen & Chuang (2010); Qiskit Aer Documentation | Depolarizing channel acts as $\mathcal{E}(\rho) = (1 - p)\rho + \frac{p}{3}(X\rho X + Y\rho Y + Z\rho Z)$. When applied to single-qubit channel transit, error probability on basis measurements is $2p/3$ for conjugate bases. | Inserted `id` channel gates on all $N$ qubits so noise uniformly affects $|0\rangle, |1\rangle, |+\rangle, |-\rangle$ during transmission. |
| **Nonce & Lifecycle Security** | NIST SP 800-38D (Dworkin, 2007) Section 8.2 | In AES-GCM, reusing a nonce under the same key completely compromises authentication. If random 96-bit nonces are used, max invocations under one key is $2^{32}$. | Enforced `session_packet_count` limit with automatic QKD re-key trigger at 100,000 packets. |
| **Sliding Window Anti-Replay** | RFC 4303 (IPsec ESP) Section 3.4.3; RFC 6347 (DTLS) Section 4.1.2.6 | A 64-bit sliding window bitmap tracks received sequence IDs. Packet with $seq \le \text{window\_bottom}$ is rejected; within window, checked against bitmap; $seq > \text{window\_top}$ advances window. | Implemented `SlidingWindowAntiReplay` with 64-packet window bitmap in Cloud Receiver. |
| **Classical Channel Authentication** | Carter & Wegman (1981); Kiktenko et al. (2017) | Classical public discussion in BB84 requires universal hash authentication (Wegman-Carter MAC) using pre-shared secret key material. | Formalized in threat model: edge devices maintain short initial pre-shared authentication key, refreshed from each successful QKD session. |
