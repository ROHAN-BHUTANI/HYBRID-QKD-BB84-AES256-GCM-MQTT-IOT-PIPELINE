Cryptographic Definitions & Standards
BB84 Quantum Key Distribution:

Single-photon state preparation in non-orthogonal conjugate bases ($+$ rectilinear, $\times$ diagonal) enabling information-theoretic secret key agreement.

Quantum Bit Error Rate (QBER):

The fundamental error detection metric: $QBER = \frac{Errors}{Sample\ Size}$. A measured error rate exceeding 11% proves channel eavesdropping, triggering an instant abort.

2-Universal Toeplitz Privacy Amplification:

Leftover Hash Lemma matrix multiplication over $\text{GF}(2)$ that eliminates Eve's mutual information and compresses error-corrected bits into an information-theoretic 256-bit symmetric AES key.

AES-256-GCM Authenticated Encryption:

NIST SP 800-38D standard providing both 256-bit confidentiality and 128-bit authentication tag verification with unique 96-bit nonces to eliminate replay attacks.

MQTT Lightweight Messaging:

OASIS publish/subscribe protocol suited for constrained IoT microcontrollers, transmitting encrypted envelopes to the cloud receiver.

MitM Tamper Protection:

Galois Message Authentication Code (GMAC) ensures any bit altered in transit by an adversary fails authentication tag verification with probability $1 - 2^{-128}$.
